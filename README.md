# Tixday – Countdown Widgets

An iOS countdown app where every date is a ticket. Each event type has its own ticket design (boarding pass, concert ticket, exam entry slip, wedding invitation, party pass, train ticket) and counts down on the Home Screen.

- SwiftUI, SwiftData, WidgetKit · iOS 17+
- Project is generated with [XcodeGen](https://github.com/yonaskolb/XcodeGen): `xcodegen generate`

See `docs/PRD.md` for the product and `docs/TODO.md` for progress.
